# 多專案研究者後台實驗分支

分支：`codex/multi-project-researcher-portal`

本分支用於驗證多專案、專案權限、研究分析與資料生命週期功能。通過測試與人工驗收前，不合併至 `main`，也不部署至正式 Cloudflare 資源。

## 已確認規則

- Cloudflare 帳戶持有人是不可移除、停用或降權的最高階研究員。
- 最高階研究員可建立及管理研究專案、專案成員與專案設定。
- 樣本標籤由各專案自行定義，不固定為偏誤分析。
- `未標記` 是「沒有任何標籤」的衍生篩選條件，不是可套用的標籤。
- 已使用標籤只能停用；未使用標籤才可永久刪除。
- 樣本可有一個專案定義的彩色星號；顏色必須同時顯示文字意義。
- 專案研究筆記包含星號定義、研究人員分工與其他備註，採自動儲存、版本檢查與歷史紀錄。
- 刪除樣本先進垃圾桶，30 天後才永久清除 D1 與 R2；最高階研究員可提前永久刪除。
- 平台測得的容量與 Cloudflare 帳戶統計必須分開標示，不能把估算值冒充帳單數據。

## 實作順序

1. D1 多專案資料模型與向下相容 migration。
2. 專案 API、專案成員權限與最高階研究員保護。
3. 專案自訂標籤、彩色星號與篩選。
4. 研究筆記自動儲存、版本衝突保護與修訂紀錄。
5. 樣本分析、化名、狀態與多研究者協作。
6. 軟刪除、垃圾桶、30 天排程清除與容量統計。
7. 動態受試者表單、專案發布版本與專屬 URL。
8. Cloudflare Access API 同步、端到端測試與人工驗收。
