# 研究者端多專案 Branch UI／UX 測試報告

日期：2026-10-08  
Branch：`codex/multi-project-researcher-portal`

## 結論

本 branch 已完成研究者端多專案資訊架構與主要互動原型，適合進入使用者確認。頁面在桌面、平板及手機尺寸均可操作，現階段不建議合併到 `main`，因為研究者端資料仍以瀏覽器內模擬資料為主，尚未全面串接 Cloudflare Access、Worker API、D1 與 R2。

建議使用者確認本輪介面後，再執行下一階段「正式資料與權限串接」全面優化。

## 已完成範圍

- 首頁顯示使用者可存取的專案、平台容量與預計釋放容量。
- 研究專案內整合樣本、題目、分析設定、筆記、研究人員及專案設計。
- 樣本每頁 10 筆，支援資格、標籤、彩色星號、分析進度及負責研究人員篩選。
- 樣本編輯器於樣本列下方展開，不必捲到頁尾。
- 研究化名、標籤名稱、彩色星號名稱及研究人員顯示名稱會同步更新相關介面。
- 研究人員可標示正在分析或完成分析；跨研究者修改提供增加註解與直接修改紀錄。
- 最高階研究員可管理細分權限，擁有者帳號受不可移除規則保護。
- 專案容量管理顯示有效語音、垃圾桶、專案總容量、占全部專案及占免費額度比例。
- 垃圾桶依日期分組，支援全選、取消單筆、還原、永久刪除及 30 天釋放比例。
- 垃圾桶中的單一樣本可播放去識別化語音；整個專案項目不提供單一音檔預聽。
- 新專案預設建立語言選擇、研究說明、同意書、背景資料、設備測試、口說任務及完成頁。
- 專案設計器支援標題、段落、醒目說明、文字、數字、下拉、單選、複選、可重複欄位、設備媒體、口說題目、完成畫面下載及分隔線。
- 欄位可新增、複製、上下移動及刪除，並可編輯必填狀態、說明、註解及選項。
- 設備測試及口說題目支援 MP4／WAV 草稿選取、格式檢查、50 MB 單檔限制與本機預覽。
- 題目列表可就地展開編輯，修改題目名稱、說明、題目音檔及受試者端啟用狀態。
- 題目啟用中狀態使用綠色，已停用狀態使用紅色。
- 樣本分析標籤可新增或移除；移除時同步清除樣本上的標籤與判定原因。
- 彩色星號標籤可新增、刪除、自訂名稱與顏色，並同步到篩選器及樣本畫面。
- 專案擁有者可修改系統顯示名稱，但 email、最高權限與不可移除保護維持鎖定。
- 完成頁預設包含不帶匿名編號的完成證明下載按鈕。

## 本輪發現並修正的 UX 問題

1. 建立專案區看不出會取得完整功能：加入七頁範本清單，並把送出按鈕改為「建立草稿並進入完整設計器」。
2. 問卷欄位過於陽春：擴充為 13 種內容／欄位類型，加入排序、複製、刪除、說明與選項編輯。
3. 媒體上傳缺少限制回饋：加入 MP4／WAV 格式與 50 MB 草稿上限檢查。
4. 單選與複選預覽不精確：改為實際 radio／checkbox 預覽，不再一律顯示下拉選單。
5. 垃圾桶只能管理、無法判斷內容：每一筆樣本加入去識別化語音播放器。
6. 平板與手機密集欄位容易擠壓：設計器設定區、垃圾桶列及新增欄位工具改為響應式排列。
7. 新增操作缺少對稱的移除入口：完成全系統增減功能稽核，補上題目移除及自訂頁面刪除。

## 尚未正式完成

- 專案、頁面、欄位、題目及媒體目前尚未持久化到 D1／R2。
- MP4／WAV 選取目前只建立本機草稿預覽，未執行正式上傳、發布版本綁定與舊檔清理。
- 受試者公開頁尚未依專案 URL 動態載入研究者發布的頁面結構。
- 垃圾桶播放器目前使用測試音檔，尚未改用受權限保護的 R2 短效讀取網址。
- 容量資料目前是模擬帳本；正式版需以 R2 物件帳本與定期 reconciliation 校正。
- 研究者細分權限目前完成規則與 UI，尚未在每一個 Worker API 端點強制驗證。
- 30 天自動永久刪除需要排程 Worker；人工永久刪除也需完成 R2、D1 與稽核紀錄的一致交易流程。
- 正式發布前仍需完成 Cloudflare Access 登入、不同權限帳號及真實端到端錄音提交測試。

## 下一階段建議

1. 建立專案設計、媒體上傳、發布版本、樣本分析、容量及垃圾桶 API。
2. 將 D1 migration 套用至 branch 測試資料庫，並以 R2 測試 bucket 驗證媒體生命週期。
3. 讓受試者端按專案 slug 載入已發布快照，同時保留現有隱私與原始錄音不上傳規則。
4. 以擁有者、專案管理員、一般研究人員三種 Access 身分執行權限矩陣測試。
5. 完成真實端到端測試後，再考慮合併至 `main` 與部署正式環境。
